# Purchase UX (Horizon theme)

Agency site stays separate. This is **Online Store → Themes → Customize** on `1wtpc0-c2`.

## Purchase path (one job)

**Homepage → featured collection → product → Add to cart → checkout**

Remove competing modules from the first viewport (stats, multi-promos, dense grids of unrelated blocks).

## Homepage (first viewport)

Keep only:

1. Brand / store name (hero-level)
2. One headline (e.g. kids costumes for school & stage)
3. One short supporting sentence
4. One CTA group → primary collection (e.g. Book Character Day or Best Sellers)
5. One dominant full-bleed costume/kids visual (theme image or collection image — **your** media only)

Do **not** put cards, floating badges, schedule strips, or multi-column promos in the hero.

## Below the fold (one job per section)

1. **Featured collection** — 4–8 products, clear “Shop all”
2. **Shop by age** — three links/images: Toddler / Little Kids / Big Kids (no card chrome if theme allows plain links)
3. **Shop by occasion** — Book Character / Halloween / Stage / Everyday
4. **Trust** — shipping window + returns summary (short), then footer

## Product page

- Large product images first
- Size selector obvious
- Sticky Add to cart if Horizon supports it for the template
- Trust line near ATC: shipping estimate + returns link
- Related: same age tag or same occasion — not random

## Cart / checkout

- Use Shopify Checkout (Shop Pay if eligible)
- No extra upsell modals that block checkout
- Confirm taxes/shipping messaging matches footer pages

## Theme editor checklist

- [ ] Hero CTA → real collection URL (not `#`)
- [ ] Announcement bar: one line max (shipping) or off
- [ ] Main menu matches `TAXONOMY.md`
- [ ] Password protection off (see `UNLOCK.md`)
- [ ] Mobile: hero CTA visible without horizontal scroll; ATC reachable
