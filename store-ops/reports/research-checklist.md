# Reusable costume category-gap checklist

Use on a later agent run or quarterly merchandising review. **Categories only — no scraping of competitor product IP.**

## 1. Pick 3–5 public retailers

Examples: national party/costume chains, 2–3 kids-costume Shopify stores, one dance/recital supplier.

## 2. Capture only navigation / category labels

For each retailer, list:

- Age bands shown
- Occasion hubs (Halloween, book day, Christmas, etc.)
- Type hubs (costumes, wigs, shoes, makeup)
- Missing labels **you** care about for school/stage kids

Do **not** download product CSVs, images, or long descriptions from competitors.

## 3. Diff against your live collections

Compare to:

- Toddler / Little Kids / Big Kids
- Book Character Day / Halloween / Stage / Everyday
- Costumes / Accessories / Footwear

## 4. Output format

Produce a prioritized table:

`rank | product type to stock | why | suggested tags`

## 5. Feed assortment

Add new types as stub rows in `templates/shopify-products-import.csv`, then replace stubs with supplier data before Shopify Import.
