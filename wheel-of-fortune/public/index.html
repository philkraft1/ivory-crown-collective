Wheel of Paradise

A chat game for TikTok LIVE Studio. Viewers join, guess letters, and solve the puzzle on stream.

On stream

  1. Double-click Start Wheel of Fortune, or run npm start in this folder.
  2. Open the host desk and lock in a puzzle.
  3. In TikTok LIVE Studio, add a Link source and paste http://127.0.0.1:8787/overlay
  4. Place that source in the upper-middle of a vertical scene. Do not add the host page.
  5. When you are LIVE, connect your TikTok username on the host desk.

Chat commands

/join gets a viewer in line. They can join at any time.

/s spins the wheel on that viewer's turn.

/g S plays one letter after the wheel stops.

/solve the whole puzzle solves it.

An exclamation mark works too, if TikTok filters the slash.
